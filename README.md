# jlr-live

JLR Korea 실시간 공유 대시보드.

- `index.html` — 대시보드 앱 (GitHub Pages로 서빙)
- `data/` — 일일/월별 데이터 (AES 암호화 저장)

코드는 Public이지만 데이터는 전부 암호화되어 저장되므로 암호 없이는 읽을 수 없습니다.

## 접근 방식

페이지 진입 시 잠금화면만 표시됩니다. 데이터는 물론 카테고리 선택 화면조차 그 뒤에 있습니다.

- **뷰어**: 열람 비밀번호 입력 → 서버 데이터를 실제로 복호화해야 통과 (조회만 가능, 임포트/저장 기능 숨김)
- **관리자**: GitHub 토큰 입력 → 기존과 동일한 전체 기능(SAP/워런티/마스터/서비스예약현황/가입자리스트 임포트, ☁ 저장) 사용

`index.html` 소스에는 실제 매출·고객 데이터가 전혀 포함되어 있지 않습니다 (전부 `data/*.enc.json`으로 이전, AES-GCM 암호화).
